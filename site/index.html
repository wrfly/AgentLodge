每个用户有自己的沙箱 agent。上游凭据一把都不用发出去。 Every user gets their own sandboxed agent, and no upstream credential is handed out.

自己部署Deploy it yourself GitHub

凭据只有一个家Credentials live in one place

key 和订阅的 refresh token 只在一个单独的服务里，加密落盘。网关每次请求换一个几小时寿命的 token，agent 手上则是绑定 (user, conversation, turn) 的 20 分钟票据。容器被拿下也偷不到东西。 Keys and subscription refresh tokens live in one service of their own, encrypted at rest. The gateway gets a token with hours to live, per request, and agents carry a 20-minute ticket bound to (user, conversation, turn). A compromised container leaks nothing worth having.

配额在 turn 内部刹住Quota stops a turn from inside it

不只是门口拦一下。agent 循环跑飞了是当场停，不是事后记账。 Not just at the door — an agent loop that runs away is stopped while it runs, not billed for afterwards.

每条出网请求可留证Every outbound request can be recorded

经审计代理落盘，完整 prompt，留多久按你的合规要求。 Through an audit proxy, with the full prompt, for as long as your compliance rules say.

一人一个容器One container per user

非 root、CapDrop ALL、内存 / CPU / PID 限额，只挂载自己的工作目录。 Non-root, all capabilities dropped, memory / CPU / PID limits, and only that user's workspace mounted.

请求怎么走Where a request goes

容器里没有 key，只有一张票据；换 key 的那一步只发生在网关进程里。 There is no key in the container, only a ticket. The swap happens inside the gateway process.

功能Features

账号Accounts

  • 邀请码注册、邮件定向邀请Invite-code registration and email invites
  • token 轮转，重放即判定泄漏并撤销全部会话Token rotation; a replayed token is treated as a leak and every session is revoked
  • 多设备管理、停用即时踢线Multi-device management, instant lockout on suspend

计量与配额Metering and quota

  • 逐次调用从 SSE 流里旁路解析 usageUsage sniffed off the SSE stream, call by call
  • 5 小时 / 周 / 月三个窗口，边界全平台统一Three windows — 5 hours, a week, a month — the same instants for everybody
  • 每个用户看到的是自己的额度，不是共享池Each user is shown their own allowance, never the shared plan's
  • 按 token 或按金额计费，历史账单锁定当时价格Billing by tokens or by money; past bills keep the price of their time

记忆与画像Memory and profile

  • 助手在对话里自己记，下次对话自动读回The assistant writes memory as you talk and reads it back later
  • 看得到、改得动、删得掉，改坏了能撤销Read it, correct it, delete it, undo a bad change
  • 每个对话一句话总结，并换成说明内容的标题Every conversation summarised in a line, and named after what it was about
  • 使用画像纯统计，不经过模型The usage profile is counted, never inferred

接入方式Ways in

  • 网页对话、附件、Markdown + 代码高亮The web app, with attachments, Markdown and syntax highlighting
  • 自带 CLI：一条命令装好，照常敲 claudeYour own CLI: one command to install, then run claude as usual
  • Anthropic Messages 与 OpenAI Responses 两套协议Both wire protocols — Anthropic Messages and OpenAI Responses
  • 多条上游同时生效，按模型路由，同一模型可挂多条、各配各的价格Several upstreams at once, routed by model — one model can be served by two of them, priced separately

运维Operations

  • 出网审计代理，完整 prompt 落盘An audit proxy that records every outbound request, full prompt
  • 额度、价格、并发、上游与模型后台热改，无需重启Quotas, prices, concurrency, upstreams and models change without a restart
  • 界面与提示 9 种语言，覆盖率由测试保证Nine languages throughout, with coverage checked by tests

部署Deploying

一条命令。密钥自己生成，装完把地址和第一个管理员的邀请码打给你。 One command. It generates its own secrets and prints the address and the first administrator's invite code when it is done.

curl -fsSL https://raw.githubusercontent.com/wrfly/AgentLodge/master/install.sh | sh

想先看再跑：curl -fsSLO …/install.sh，读完 sh install.sh。 端口和域名用 PORT=8080 SITE=lodge.example.com 覆盖；填域名 Caddy 会自动签证书。 To read it first: curl -fsSLO …/install.sh, then sh install.sh. Override with PORT=8080 SITE=lodge.example.com; give it a domain and Caddy gets a certificate.
